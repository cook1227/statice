# Statice Goods Register

GitHub Pages 用の1ページ完結型グッズ計算機です。

## ファイル
- index.html
- header.png

この2ファイルを GitHub リポジトリの同じ階層に置けば動きます。

## 主な機能
- スマホ / PC レスポンシブ
- ヘッダー画像
- 画面上部に合計金額を固定表示
- 12商品の数量 +/-、小計、合計
- 選択商品のみ購入リストに表示
- 購入リストをPNG画像で保存
- 数量をブラウザ内に自動保存（リロードしても保持）
- 全数量リセット

## GitHub Pages
リポジトリへ index.html と header.png をアップロードし、
Settings > Pages から公開元のブランチを設定してください。
